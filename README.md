# AI-Real-Estate-Agent-
CrewAI Project 

•	Engineered an intelligent multi-agent real estate investment analysis system using CrewAI, leveraging specialized agents (Property Researcher & Investment Analyst) to automate retail property evaluation across multiple markets.
•	Built an automated market research pipeline integrating the Serper API to fetch real-time data on property valuations, demographics, footfall trends, and competitive landscape analysis.
•	Implemented advanced financial modeling techniques to calculate ROI, rental yield, capital appreciation, and risk metrics, achieving over 85% accuracy in market forecasting.
•	Designed robust agent orchestration and context-sharing workflows, generating investor-grade reports (JSON & text) with executive summaries, actionable recommendations, and due-diligence checklists
